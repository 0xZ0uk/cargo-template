# @shipment/onpage-plugin

The Payload plugin: on-page endpoints (`/api/onpage/*`), access checks through Payload's own access operations, the schema serializer, marker hooks, preview-link tokens, and the "Edit on page" / "Copy preview link" admin controls (`@shipment/onpage-plugin/admin`).

Part of Shipment's fork of payload-onpage. See [packages/onpage/README.md](../README.md).
